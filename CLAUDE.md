socket-free portfolio site ("Amir Codes Space") for amircodess.com, hosted as a static site on Cloudflare Pages.

- The code currently in the repo is the original Office Board (Express + Socket.IO + Three.js). Replace it, don't extend it.
- Never commit secrets (Spotify/GitHub tokens) or any `.env` file.
- Don't invent personal content (songs, films, books); use empty states until Amir provides data.
